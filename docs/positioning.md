# Positioning

## The Sentence

The Open Housing Data Standard is an open data standard for New York's affordable housing applications, with a runnable reference implementation.

## The Longer Version

This project defines the interface layer a modern affordable housing ecosystem should be able to speak: structured application packets, tenant consent grants, document requests, status events, audit trails, OpenAPI endpoints, MCP tools, and synthetic test workflows.

It is a public-good reference architecture.

## What To Emphasize

- interoperability
- auditability
- tenant consent
- synthetic data
- public-sector usability
- responsible AI
- vendor neutrality
- future compatibility

## Language Discipline

Prefer language that is affirmative, civic, and implementation-oriented. Keep the tone calm and rigorous. Let the artifact's quality carry the confidence.

## Good Phrases

- "reference interface"
- "synthetic test harness"
- "agent-ready with human review"
- "auditable workflow surface"
- "future-compatible integration layer"
- "designed for public-sector review"
- "open enough for an ecosystem, bounded enough for trust"

## Phrases To Leave Out

- "we can bypass"
- "this replaces"
- "city systems are broken"
- "vendor capture"
