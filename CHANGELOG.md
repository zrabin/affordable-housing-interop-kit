# Changelog

## 0.1.0 - 2026-08-04

First public baseline of the **Open Housing Data Standard** (previously published as the Affordable Housing Interop Kit).

- Renamed the effort to Open Housing Data Standard; the name is a working title pending co-steward input.
- Added the **notice** schema (`schemas/notice.schema.json`) and the **form** schema (`schemas/form.schema.json`, instance-level modeling of required certifications such as the Tenant Income Certification), each with example, tests, and OpenAPI path, completing the six core building blocks: application packet, status event, document request, form, notice, audit event.
- Added [CHARTER.md](CHARTER.md) (the principles and what supporting means) and [SUPPORTERS.md](SUPPORTERS.md).
- Opened the contribution model: issues, discussions, and pull requests are now accepted with maintainer review; email participation carries equal weight.
- Rewrote the README as a plain-language introduction with lifecycle and ecosystem visuals.
- Added [docs/nyc-context.md](docs/nyc-context.md) (the Standard in New York terms) and [docs/concepts.md](docs/concepts.md).
- Added a co-steward path to [docs/governance.md](docs/governance.md).
