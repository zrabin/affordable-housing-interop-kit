# Schemas

This directory contains JSON Schemas for the six core building blocks of the Open Housing Data Standard.

Current objects:

- `application-packet.schema.json` (includes applicant, household, consent grants, and documents)
- `status-event.schema.json`
- `document-request.schema.json`
- `form.schema.json`
- `notice.schema.json`
- `audit-event.schema.json`

These schemas are reference contracts for alignment conversations and implementation planning. Plain-language definitions live in [docs/concepts.md](../docs/concepts.md).
